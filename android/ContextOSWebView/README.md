# ContextOS WebView

Minimal Android WebView shell for ContextOS Code Reader.

It opens:

```text
http://47.108.145.21:5000/ui/code
```

The app keeps WebView local storage, so the ContextOS view token should stay saved
after the first login.

Build locally with Android Studio by opening this directory, or use the GitHub
Actions workflow `Build ContextOS WebView APK`.
